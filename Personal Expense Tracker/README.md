Personal Expense Tracker 💰

A Python-based command-line application that helps users record, manage, and track their daily expenses. It stores expense records in CSV files and provides category-wise spending summaries.

📌 Features

Add Expenses: Record expenses with date, category, description, and amount.

View Expenses: Display all saved expense records.

Filter Expenses: Search expenses by category or date.

Category-wise Summary: Calculate total spending for each category.

Total Spending: View the total amount spent.

CSV Storage: Save expense records permanently in a CSV file.

Input Validation: Validate dates and amounts to avoid invalid entries.

Sample Data: Includes 10 fictional expense records for testing.

🛠️ Technologies Used

Python 3

CSV Module

Datetime Module

OS Module
